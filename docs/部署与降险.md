# 部署与降险

## 一、接入 SnowLuma（唯一支持的 QQ 接入）

内核是 **OneBot 11 反向 WS 服务端**：协议端（SnowLuma）主动连进来，内核无需公网 IP。**禁止 NapCat**（本项目不内置、不捆绑、不推荐）。

**推荐：内嵌托管（默认开启）**
1. 本机安装 PC 版 QQ（QQNT）并登录**专用小号**（绝不用主力号）
2. 直接启动 parallel（parallel.cmd 或 `node bin/parallel.js`）——内核自动下载 SnowLuma 发行包、预写反向 WS 配置（token 自动注入）并拉起
3. 桌面端登录页看到"SnowLuma 已就绪"后，在 QQ 客户端窗口完成登录（或到 SnowLuma 控制台 http://127.0.0.1:5099 按引导接入 QQ 进程），协议端连入即自动进入控制台

**手动方式（托管关闭时）**
1. 下载 [SnowLuma](https://github.com/SnowLuma/SnowLuma) 发行包并解压，运行 `launcher.bat`，在其 WebUI 完成首次引导
2. 在其 WebUI 添加 **WebSocket 客户端**：
   - URL: `ws://127.0.0.1:3001/onebot`（与 `data/config.json` 的 `onebot.*` 一致）
   - accessToken: `data/secrets.json` 里的 `onebotAccessToken`
3. 保存后 SnowLuma 主动连入，看到 `协议端已连接（反向 WS，token 校验通过）` 即接入成功。

token 鉴权是强制的：无 token / 错 token 的连接在适配器层直接拒绝。

## 二、首次配置

1. 桌面端 <http://127.0.0.1:3080>（token 在 `secrets.json` 的 `uiToken`）
2. 「设置」→ 主人 QQ 白名单（`masterIds`）——人设切换、插件安装、全局默认、主动推送开关都在主人手里
3. 「模型」→ 配置一个已接入的供应商（DeepSeek 填 key 即可；gemini-3.8-flash 是占位，显示"未接入"）
4. 群聊里管理员发 `/插件 开启 chat`（聊天）、`/插件 开启 sandbox`（沙箱）等

## 三、降险清单（务必阅读）

1. **专用小号**，绝不挂主力号；新号先正常使用一段时间再上 bot。
2. bot 号与常用号**分开 IP/设备**；频繁掉线换 IP/换号。
3. 登录后**第一周是风控敏感期**，掉线属正常，重新登录即可；稳定后通常长稳。
4. 同一协议端**不双开**同一账号；不与 PC 端 QQ 同时在线。
5. WS/HTTP 端口只监听 127.0.0.1/内网；access token 必配（已强制）。
6. 内核默认已做：回复限速 + 随机抖动；群聊仅 @/回复唤醒；**主动推送默认关闭**（开启入口在主人手里，UI 标注风控风险）。
7. 接受"约 30 天重新登录一次"为协议端常态。
8. **风险声明**：任何个人号协议接入都违反 QQ 用户协议，账号存在被限制/临时风控甚至封禁的可能，请自行评估并只使用可承受损失的账号。

## 四、数据与备份

- `data/config.json`：内核配置（原子落盘，保留 3 份滚动 `.bak`）。**不要运行时手改文件**，一切变更走 UI/API。
- `data/secrets.json`：全部密钥（uiToken / onebotAccessToken / providerKeys / 插件 secret 配置）。
- `data/parallel.db`：SQLite（用户记忆/开关状态/用量/表情包索引）。WAL 模式。
- `data/sandbox/`：会话沙箱（TTL 自动清理）；`data/sessions/`：追加式会话日志（JSONL，可回放）。
- 备份 = 拷走整个 `data/` 目录。

## 五、常见问题

| 现象 | 处置 |
|------|------|
| SnowLuma 连不上 | 确认 QQ 客户端已登录、SnowLuma WebUI 里 wsClients 指向正确端点且 token 粘对；看其网络日志握手错误 |
| 连上但 bot 不回话 | 群插件全关（默认就是全关）：管理员发 `/插件 列表` → `/插件 开启 chat` |
| 模型报"未接入" | gemini-3.8-flash 是占位；去「模型」页切 DeepSeek 并填 key |
| 插件自动停用 | 报错中心看原因（同错 3 次）；处置后主人重载 |
| 沙箱执行失败 | 确认 `python` 在 PATH（或设环境变量 `PARALLEL_PYTHON`）；查沙箱页执行限额 |
